# mcp

The 2earl MCP gateway, served at `https://mcp.2earl.com/mcp`: one MCP endpoint for AI assistants,
signed in with a 2earl account ([login.2earl.com](https://github.com/2earl/login)). It offers
2earl's own tools and the tools of MCP servers each user connects with their own accounts.

**Status:** design (phase M0). Nothing is deployed yet.
